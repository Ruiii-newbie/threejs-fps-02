A complete round-based tactical FPS in three.js: 5v5, bomb plant/defuse objective, money and a buy menu between rounds, grenades, bot AI that holds routes and reacts to sight and sound, and gunplay where stopping to aim pays.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
